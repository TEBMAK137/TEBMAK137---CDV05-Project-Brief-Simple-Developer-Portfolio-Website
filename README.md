# Tebogo Makgakga – Developer Portfolio

 

A clean, responsive developer portfolio website built with HTML, CSS, and JavaScript. It showcases projects, technical skills, education, work experience, and contact information in a warm, accessible design.

 

## 🎨 Color Scheme

 

- Main background: `#f1efd3` (beige)

- Hero/secondary background: `#e9cca8` (warm beige)

- Card borders & accents: `rgb(213, 186, 152)`

- Heading borders: `rgb(128, 100, 30)` (deep brown)

 

## 🚀 Features

 

- **Fully responsive** – works on desktop, tablet, and mobile.

- **Project showcase** – three featured projects with descriptions, tech tags, and placeholder live/github links.

- **Resume section** – about me, education, work experience, skills, and certificate buttons.

- **Contact section** – social media links and a functional contact form powered by FormSubmit.

- **Smooth scrolling** + active navigation highlight.

- **Clean, well-commented code** – separated HTML, CSS, and JS files.

- **SEO best practices** – meta tags for description, keywords, author.
